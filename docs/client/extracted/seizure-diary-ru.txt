Инструкция
Дневник приступов будет сопровождать вас в течение месяцев кетогенной диетотерапии (КДТ). Рекомендуется ежедневно уделять несколько минут его заполнению. Чем больше информации будет зарегистрировано, тем полезнее окажется этот дневник при обсуждении результатов с лечащей командой.
Обозначения типов приступов
A — Абсанс
C — Приступ с падением
F — Фокальный приступ
FG — Фокальный приступ с вторичной генерализацией
M — Миоклонический приступ
T — Тонический приступ
TC — Тонико-клонический приступ
O — Другое (указать)
Пример: если утром произошло 5 абсансов, в графе "Утро (06:00–12:00)" следует записать "5A".
Шаблон регистрации приступов
Для каждого месяца фиксируйте количество приступов по времени суток: Утро (06:00–12:00) День (12:00–18:00) Вечер (18:00–00:00) Ночь (00:00–06:00) Итог за день и итог за месяц.
