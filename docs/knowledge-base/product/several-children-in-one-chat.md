# Два ребёнка в одном чате — как переключаться

## Короткий ответ

Пришлите боту код второго ребёнка в тот же чат. Бот подключит его, первый
ребёнок останется. Внизу появится кнопка «👶 Ребёнок: имя» — ею выбирают, чей
дневник вести сейчас.

## Как выбрать ребёнка в боте

Нажмите «👶 Ребёнок: имя» и выберите имя в списке. Выбранный отмечен галочкой.
Бот ответит: «Готово: записи теперь идут для …».

Записи уходят тому ребёнку, который выбран. Бот называет его в каждом вопросе и
в подтверждении: «Записано ✓ Имя: …». Если в этот момент вы что-то записывали,
запись начнётся заново.

## Как выбрать ребёнка в приложении

В приложении над экранами появляется список «Ребёнок». Выберите в нём другое
имя — все экраны откроются уже для этого ребёнка. Выбор запоминается на этом
телефоне.

## Напоминания для двух детей

Напоминания настраиваются для каждого ребёнка отдельно. Чтобы было понятно, о
ком речь, над текстом напоминания стоит строка «👶 Имя».

## Когда обращаться к врачу

Если кнопка показывает не того ребёнка или чужое имя — не делайте записей и
скажите об этом врачу.
