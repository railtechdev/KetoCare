# ADR-0036. Возврат сети в WebView Telegram

Дата: 12.09.2026. Статус: принято.

## Контекст

TanStack Query решает, есть ли сеть, через `onlineManager`. Он стартует с «в
сети» и меняет состояние только по событиям окна `online` и `offline`.
Запросы по умолчанию идут в режиме `networkMode: "online"`: без сети они не
отказывают, а встают на паузу (`fetchStatus: "paused"`) и ждут события
`online`.

В обычном браузере событие приходит. Во встроенном WebView Telegram гарантии
нет: после свёрнутого приложения, сна телефона или смены Wi-Fi на мобильную
сеть `online` может не прийти. Тогда запросы Mini App остаются на паузе при
живой связи, и экран показывает загрузку, пока приложение не перезапустят.
Записи этого не касаются: они отказывают сразу (ADR-0034).

Вопрос технический, пользователь поручил его агенту (12.09.2026).

## Решение

Mini App подключает к `onlineManager` свой источник через
`onlineManager.setEventListener` — так документация TanStack Query предлагает
заменять определение сети (тот же приём используют для React Native).
Источник (`apps/miniapp/src/lib/connectivity.ts`):

- слушает `online` и `offline`, как и стандартный;
- перепроверяет `navigator.onLine` на `visibilitychange` и на событии Telegram
  `activated` («Occurs when the Mini App becomes active (e.g., opened from
  minimized state or selected among tabs)», Bot API 8.0,
  core.telegram.org/bots/webapps);
- спрашивает `navigator.onLine` сразу при подключении: стандартный источник
  этого не делает, и открытое без сети приложение считало бы себя в сети.

## Последствия

- `navigator.onLine === true` связи не гарантирует. Ошибка в эту сторону
  дешёвая: запрос уйдёт и откажет «нет связи» (ADR-0034), а не повиснет.
- Кабинет не трогаем: в настольных и мобильных браузерах `online` приходит
  надёжно, а перезапрос при возвращении фокуса паузу не снимает — это делает
  только `onlineManager`, поэтому источник меняется там, где событие ненадёжно.
- Старые клиенты Telegram без Bot API 8.0 события `activated` не шлют; для них
  остаётся `visibilitychange`.
