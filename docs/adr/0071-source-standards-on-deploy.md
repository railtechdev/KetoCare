# ADR-0071. Справочники-источники загружает выкат

Дата: 12.11.2026. Статус: принято командой разработки. Медицинских констант решение не меняет.

## Контекст

Рабочий справочник собирается из двух справочников-источников: таблиц книги Нестеренко
«Лечебное питание» (2011) и USDA SR Legacy (ADR-0067, ADR-0070). Файлы лежат в
`docs/import/sources`. На стенд они должны были попасть через API под учётной записью
администратора с паролем и вторым фактором. Это работа для человека с доступом, и она
задерживала клинику: без источников диетолог не может собрать рабочий справочник.

## Решение

Источники загружает выкат так же, как документы детских садов (ADR-0060).
`infra/scripts/load_source_standards.py --on-deploy` берёт автором первого
действующего администратора. Для каждого источника он заводит стандарт вида
«внешний документ», загружает строки тем же разбором CSV, что и ручка импорта, и
закрывает стандарт. Всё это идёт одной транзакцией на каждый стандарт и пишется в
журнал аудита.

- Файл с ошибкой или с числом строк, отличным от ожидаемого (77 и 76), не
  загружается вовсе.
- Стандарт с тем же названием не трогается. Если он закрыт, работа сделана. Если
  открыт, его начал человек, и выкат не правит чужую работу.
- Отказ загрузки не останавливает выкат приложения.

## Последствия

- В образ `api` теперь попадает `docs/import/sources`.
- Новая редакция источника — это новый файл и новое название стандарта в
  `api/services/source_standards.py`. Закрытый стандарт не переписывается.
