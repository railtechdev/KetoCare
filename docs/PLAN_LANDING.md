## Правило изоляции (главное)

Над репозиторием работают параллельно. Уже произошло: серверная часть заявок
(шесть новых файлов и правки в шести существующих) была стёрта из рабочего
дерева внешним действием между шагами — восстанавливать пришлось с нуля.

**Поэтому:** работа по этой теме идёт только в ветке `feat/landing-site` и
только через отдельный git worktree, а не в общем рабочем дереве. Готовый
кусок сразу коммитится — незакоммиченное здесь не переживает соседа.

```bash
git worktree add ../ketocare-landing feat/landing-site
```

### 4. Решения, которые нужны от вас

- **Почта и Telegram.** Сейчас `hello@ketocare.uz` и `t.me/ketocare` — из
  макета. Неотвечающий контакт на лендинге хуже отсутствующего.
- **Узбекский и английский — машинный перевод.** До показа клиникам нужна
  вычитка носителем; сокращения типов приступов (`TK/MK/AB`) нужно
  подтвердить у эпилептолога. Отдельно: ТЗ §16 относит узбекскую локализацию
  к нереализуемому — маркетинговый сайт это или всё же локализация, стоит
  зафиксировать в ADR.
- **Куда попадают заявки.** Ручка их пишет, но никто о них не узнаёт: ни
  письма, ни экрана в админке. Для сбора фокус-группы нужен хотя бы один из
  двух способов.
