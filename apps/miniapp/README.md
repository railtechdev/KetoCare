# Mini App (`apps/miniapp`)

Приложение семьи внутри Telegram: React 19 + Vite поверх кита `@ketocare/ui`
и клиента `@ketocare/api-client`. Роутера и cookie нет: экран один, токены
живут в памяти вкладки (раздел 5.2 ТЗ, ADR-0017). Устройство экранов —
[ADR-0075](../../docs/adr/0075-mini-app-four-tabs-and-telegram-features.md).

```
pnpm --filter @ketocare/miniapp dev          # http://localhost:$MINIAPP_PORT
make miniapp-link                            # адрес запуска с подписью для своей базы
pnpm --filter @ketocare/miniapp exec vitest run
```

Всё, что приложение знает о Telegram, — в `src/lib/telegram.ts` и
`src/lib/theme.ts`. Каждая возможность новее Bot API 6.0 спрашивает
`isVersionAtLeast`, и у каждой есть поведение вне Telegram.

## Параметр запуска (договор с ботом)

Бот открывает приложение сразу на нужном месте — например, кнопкой под
напоминанием «Кетоны не записаны». Разбор — `src/lib/launchTarget.ts`, тесты —
`src/lib/launchTarget.test.ts`.

**Где лежит значение** (берётся первое найденное):

1. `open` в строке запроса: `https://tma.<домен>/?open=diary-ketones`. Так
   открывает кнопка `web_app` с адресом приложения — Telegram дописывает
   подпись в хеш, а запрос оставляет.
2. `open` в хеше рядом с подписью: `#tgWebAppData=…&open=diary-ketones`.
3. `tgWebAppStartParam` (в хеше или запросе) и `start_param` в строке запуска —
   так приходит `startapp` прямой ссылки `t.me/<бот>/<приложение>?startapp=…`.

**Значения:**

| Значение             | Что открывается                                  |
| -------------------- | ------------------------------------------------ |
| `today`              | «Сегодня»                                        |
| `menu`               | меню на сегодня                                  |
| `diary`              | «Дневник»                                        |
| `diary-seizures`     | форма новой записи «Приступ»                     |
| `diary-ketones`      | форма «Кетоны»                                   |
| `diary-weight`       | форма «Вес»                                      |
| `diary-medications`  | форма «Лекарство»                                |
| `diary-side-effects` | форма «Самочувствие»                             |
| `settings`           | настройки                                        |
| `family`             | настройки, раздел «Близкие»                      |
| `reminders`          | настройки, раздел «Напоминания»                  |

Незнакомое значение открывает «Сегодня», а не ошибку: бот может оказаться
новее приложения. Параметр применяется один раз за запуск — смена ребёнка его
не повторяет. Еды среди форм нет намеренно: её отмечают в меню (ADR-0044).

Значения меняются только вместе с ботом: тест держит список, а бот —
свою сторону договора.
