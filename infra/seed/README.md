# Стартовая база продуктов

`products-usda.csv` — 98 позиций для CSV-импорта (`POST /api/v1/products/import`,
экран администратора «Продукты → Импорт»).

**Это не одобренная клинически база.** Цифры взяты из открытого источника и
проверены на согласованность, но ни один врач их не смотрел. До фокус-группы
файл обязан пройти проверку медицинской команды — вопросы 6 и 26 в
`docs/medical/OPEN_QUESTIONS.md`.

## Откуда цифры

Источник — **USDA FoodData Central, набор SR Legacy (релиз апреля 2018)**,
общественное достояние. Каждая строка несёт свой идентификатор записи в поле
`source_version`, поэтому любое число проверяется по ссылке:

```
https://fdc.nal.usda.gov/food-details/173410      # Масло сливочное
```

Колонка `name_en` хранит точное описание позиции из USDA. Она нужна не для
интерфейса, а для сверки: если русское название покажется неточным, видно, что
именно за ним стоит.

`name_uz` оставлена пустой намеренно. Неверный перевод названия продукта в
клиническом интерфейсе — это выбранный не тот продукт при расчёте; узбекские
названия должна дать медицинская команда, а не переводчик.

## Почему именно USDA

Решает не лицензия, а одна строка в ядре: `NET_CARBS_DEFAULT = False`, и
net-углеводы считаются как `max(carbs − fiber, 0)`. Значит `carbs_100g` в
KetoCare — **общие углеводы, включающие клетчатку**. USDA даёт ровно это
(«carbohydrate, by difference»), пересчёт не нужен.

Российские и советские таблицы приводят углеводы **без** клетчатки — их
пришлось бы пересчитывать построчно. Open Food Facts не подходит принципиально:
проект сам не фиксирует, включена ли клетчатка, а это ровно то число, которое
кормит расчёт кетосоотношения.

## Как это собрано

1. Скачан `FoodData_Central_sr_legacy_food_csv_2018-04.zip` (5,8 МБ).
2. Из `food.csv` и `food_nutrient.csv` собраны пять величин на 100 г:
   энергия (нутриент 1008, ккал), жиры (1004), белки (1003),
   углеводы by difference (1005), клетчатка (1079). Полный набор есть у 7231
   позиции из 7793.
3. Отобраны базовые продукты, осмысленные для кетодиеты и узнаваемые в регионе:
   жиры, молочное, яйца, мясо (включая баранину), рыба, орехи, низкоуглеводные
   овощи. Плюс несколько высокоуглеводных (рис, мука, фрукты) — врачу нужно
   показывать семье и то, что не подходит.
4. Каждое совпадение проверено глазами: подпись описывает **именно ту** строку
   USDA, а не похожий местный продукт. На этой проверке отсеялись четыре
   первоначальные ошибки — например, `Cream, fluid, light whipping` это 31%
   жирности, а не 20%, а `Cheese, cottage` это не совсем творог.
5. Файл прогнан настоящим парсером проекта (`api.services.product_import.parse_csv`):
   98 строк, ноль ошибок.

## Что отсеялось и почему

**Масло льняное** (`fdc 167702`) не вошло: у него жиры 99,98 г и белки 0,11 г на
100 г, в сумме 100,09 — физически невозможно. Это артефакт независимого
округления в самом USDA, но правило импорта «сумма макросов ≤ 100 г»
справедливо отклоняет такую строку, а значения источника править нельзя.
Вопрос о допуске на округление — 27 в `OPEN_QUESTIONS.md`.

**Кефир** есть в USDA только нежирный и брендовый (`Kefir, lowfat, plain,
LIFEWAY`). Оставлен с честным названием «Кефир нежирный»: для кетодиеты он
малополезен, но продукт узнаваемый.

**Местных продуктов нет** — курта, сузьмы, катыка в USDA не существует. И не
должно: плов, лагман, сомса в модели KetoCare это **рецепты над продуктами**, а
не продукты. Локализация решается рецептами и колонкой `name_uz`.

## Как загрузить

Администратором в кабинете: «Продукты» → «Импорт», выбрать файл. Сначала пойдёт
предпросмотр с построчным отчётом — импорт произойдёт только после подтверждения.
Категории создавать заранее не нужно: импорт заводит их сам по колонке `category`
(отдельной ручки для категорий в API нет — вопрос 26).

**Осторожно с регистром.** Сравнение имени категории точное и регистрозависимое,
уникального индекса нет: «Жиры и масла» и «жиры и масла» из двух файлов дадут два
разных справочника. Держитесь написания из этого файла.

Повторная загрузка того же файла безопасна: совпадающие названия отсеются как
дубли, остальные строки импортируются.
